# appAndroid - React Native App

## Tech Stack
- React Native + Expo
- EAS Build (for APK release)

## Key Files
- App.js         Root component
- app.json       Expo config
- eas.json       EAS build config

## Build Commands
- build_apk_debug.bat      Build debug APK
- build_apk_release.bat    Build release APK

## Git Commit Rules
Format: type: short description in english, lowercase
No Co-Authored-By lines. Subject line only.
