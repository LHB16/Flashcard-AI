📖 Flashcard AI — User Guide

Section 1: 🚀 Getting Started

  • Login with Google Drive to automatically synchronize your flashcard decks.
  • Alternatively, you can manually upload a decks.json file if you prefer offline usage or local backup.

Section 2: 🃏 Flashcard Mode

  • Tap the card or press Space to flip and reveal the answer.
  • Swipe right (✅) if you know it, or swipe left (❌) if you don't.
  • Shortcuts: Use ← and → arrow keys, or press R to undo a swipe.

Section 3: 🧠 Quiz Mode

  • Select the correct answer and click Next to advance.
  • Use the ← button to review previous answers (read-only mode).
  • Use the → button to skip a question and defer it to the end of the session.
  • The system will automatically save your progress so you can resume exactly where you left off.

Section 4: ✨ AI Scan

  • Requires Google Drive login to function.
  • Input your Gemini API keys (these are saved securely and automatically to your Drive AppData).
  • Select a folder of images, and the system will automatically extract them and generate a flashcard deck.
  • Supported formats include: PNG, JPG, WebP, and BMP.
  • Adding multiple API keys allows the system to process images in parallel, significantly speeding up extraction.

Section 5: 📌 Tips & Shortcuts

  • Pin your favorite decks to the top of the list for easy access.
  • Sort decks alphabetically using the A-Z or Z-A buttons.
  • Toggle Dark/Light mode using the bulb icon for comfortable study sessions.
  • AI tools like Brave Leo can read quiz questions aloud to assist with learning.
